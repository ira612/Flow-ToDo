# 📌 Project Overview

Flow · To-Do is a productivity-focused web application that helps users organize daily tasks efficiently while making task management enjoyable through modern UI design, smooth animations, motivational features, and intelligent task tracking.
The application emphasizes clean design, smooth user interactions, and efficient client-side state management while maintaining excellent performance without external libraries.

Unlike a basic to-do application, Flow combines productivity tools with engaging user experience elements such as streak tracking, achievement badges, animated celebrations, drag-and-drop task management, and persistent storage.

The project is developed entirely using **HTML5**, **CSS3**, and **Vanilla JavaScript** without relying on external frameworks.

# ✨ Features

## 📝 Task Management

- Add new tasks
- Edit tasks by double-clicking
- Delete tasks
- Mark tasks as completed
- Rearrange tasks using Drag & Drop
- Automatically save changes

---

## 🔍 Search & Filtering

- Live search
- Highlight matching search text
- Filter tasks by:
  - All
  - Active
  - Completed

---

## 🎯 Priority Levels

Each task supports priority selection.

- 🔴 High
- 🟡 Medium
- 🟢 Low

---

## 😊 Mood Selection

Assign a mood to every task.

- 😊 Happy
- 🎯 Focused
- 😌 Chill
- ⚡ Energetic
- 🤔 Thoughtful

---

## 📅 Due Dates

Tasks support due dates with smart labels.

Examples:

- Today
- Tomorrow
- 5 Days Left
- Yesterday
- Overdue

---

## 🔥 Daily Productivity Streak

The application tracks your daily productivity.

Features include:

- Consecutive day tracking
- Automatic streak saving
- Streak reset after inactivity
- Celebration every 5-day milestone

---

## 🏆 Achievement Badges

Unlock achievements when reaching milestones.

Examples:

- 🌟 First 5 Tasks Completed
- 🏅 10 Tasks Completed
- 🏆 25 Tasks Completed
- 🔥 5-Day Streak
- 🎉 Complete Every Task

---

## 📊 Dashboard

Live dashboard displays:

- Total Tasks
- Remaining Tasks
- Completed Tasks
- Completion Percentage
- Daily Streak Counter

## 🌟 Celebration Effects

Completing important milestones triggers:

- Sparkle Particle Animation
- Achievement Toasts

## 🌗 Dark / Light Mode

Supports:

- Light Theme
- Dark Theme

## 💬 Motivational Quotes

Random motivational quotes appear every 30 seconds to encourage productivity.

---

## 👋 Smart Greetings

Greeting changes according to time.

Examples:

- 🌅 Good Morning
- ☀️ Good Afternoon
- 🌇 Good Evening
- 🌙 Good Night

## 💾 Persistent Storage

The application automatically saves:

- Tasks
- Completion Status
- Priority
- Mood
- Due Date
- Current Filter
- Theme
- Productivity Streak

Everything is stored using **Browser LocalStorage**.

## ⌨️ Keyboard Shortcuts

| Key | Action |

| N | New Task |
| E | Edit Selected Task |

| Esc | Close Task Dialog |

Tasks can be reordered using HTML5 Drag & Drop API.

The new order is automatically saved.
